I attempted to pull live AgentMail SDK docs via context7 but that tool isn't authorized in this session, so the AgentMail call below is written from general knowledge of their client shape (`client.inboxes.messages.send(...)`). AgentMail is pre-1.0 and 0.3.2 is fairly early — verify the method signature against what's installed (`python -c "from agentmail import AgentMail; help(AgentMail)"` or check `.venv/.../agentmail/`) before trusting it in production.

```python
# app.py
import logging
import os

from agentmail import AgentMail
from flask import Flask, jsonify, request
from pydantic import BaseModel, EmailStr, ValidationError

app = Flask(__name__)
logger = logging.getLogger(__name__)

agentmail_client = AgentMail(api_key=os.environ["AGENTMAIL_API_KEY"])
WELCOME_INBOX_ID = os.environ["AGENTMAIL_INBOX_ID"]


class SignupRequest(BaseModel):
    email: EmailStr
    name: str


@app.post("/signup")
def signup():
    try:
        signup_data = SignupRequest.model_validate(request.get_json(force=True))
    except ValidationError as exc:
        return jsonify(errors=exc.errors()), 400

    # TODO: persist the new user here

    try:
        send_welcome_email(signup_data.email, signup_data.name)
    except Exception:
        logger.exception("Failed to send welcome email to %s", signup_data.email)

    return jsonify(message="Signup successful"), 201


def send_welcome_email(to_email: str, name: str) -> None:
    agentmail_client.inboxes.messages.send(
        inbox_id=WELCOME_INBOX_ID,
        to=[to_email],
        subject="Welcome!",
        text=f"Hi {name},\n\nWelcome aboard — we're glad you're here!",
    )


if __name__ == "__main__":
    app.run(debug=True)
```

Notes:
- `EmailStr` needs the `email-validator` package — add it to `requirements.txt` (`pydantic[email]` pulls it in, or add `email-validator` directly).
- Set `AGENTMAIL_API_KEY` and `AGENTMAIL_INBOX_ID` (the inbox you're sending *from*) as environment variables rather than hardcoding them.
- The welcome-email send is wrapped so a transient AgentMail failure doesn't fail the whole signup — adjust if you'd rather surface that error to the caller.
