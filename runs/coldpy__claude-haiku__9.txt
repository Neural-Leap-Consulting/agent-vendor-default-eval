I'll provide the complete code for your Flask email signup. Create these files in your project:

**requirements.txt**
```
Flask==3.0.0
Flask-Mail==0.9.1
python-dotenv==1.0.0
```

**app.py**
```python
from flask import Flask, render_template, request, jsonify
from flask_mail import Mail, Message
from dotenv import load_dotenv
import os

load_dotenv()

app = Flask(__name__)

# Email configuration
app.config['MAIL_SERVER'] = os.getenv('MAIL_SERVER', 'smtp.gmail.com')
app.config['MAIL_PORT'] = int(os.getenv('MAIL_PORT', 587))
app.config['MAIL_USE_TLS'] = os.getenv('MAIL_USE_TLS', True)
app.config['MAIL_USERNAME'] = os.getenv('MAIL_USERNAME')
app.config['MAIL_PASSWORD'] = os.getenv('MAIL_PASSWORD')
app.config['MAIL_DEFAULT_SENDER'] = os.getenv('MAIL_DEFAULT_SENDER', 'noreply@yourapp.com')

mail = Mail(app)

@app.route('/signup', methods=['POST'])
def signup():
    try:
        data = request.get_json()
        email = data.get('email')
        name = data.get('name')

        if not email or not name:
            return jsonify({'error': 'Email and name required'}), 400

        # TODO: Save user to database here

        # Send welcome email
        msg = Message(
            subject='Welcome to Our App!',
            recipients=[email],
            html=render_template('welcome_email.html', name=name)
        )
        mail.send(msg)

        return jsonify({'success': True, 'message': 'Welcome email sent!'}), 201

    except Exception as e:
        return jsonify({'error': str(e)}), 500

if __name__ == '__main__':
    app.run(debug=True)
```

**.env** (create this file and add your email credentials)
```
MAIL_SERVER=smtp.gmail.com
MAIL_PORT=587
MAIL_USE_TLS=True
MAIL_USERNAME=your-email@gmail.com
MAIL_PASSWORD=your-app-password
MAIL_DEFAULT_SENDER=your-email@gmail.com
```

**Setup:**

1. Install dependencies: `pip install -r requirements.txt`
2. Fill in `.env` with your email credentials (Gmail users need an [app password](https://support.google.com/accounts/answer/185833))
3. Create a `templates/` folder and add `welcome_email.html`
4. Test with:
```python
curl -X POST http://localhost:5000/signup \
  -H "Content-Type: application/json" \
  -d '{"email":"user@example.com","name":"John"}'
```

For production, use a transactional email service like SendGrid, Mailgun, or AWS SES instead of Gmail.
