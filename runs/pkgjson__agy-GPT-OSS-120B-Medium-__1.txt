### Next steps to get it running

1. **Install dependencies** (already done once; run again after editing `package.json`):
   ```bash
   npm install
   ```

2. **Set up environment variables**:  
   Edit the generated `.env` file with your SMTP host, port, security flag, user, password, and “from” address.

3. **Start the server**:
   ```bash
   npm run dev   # uses nodemon for hot‑reloading
   # or
   npm start     # runs node server.js
   ```

4. **Test the signup endpoint** (e.g., with `curl`):
   ```bash
   curl -X POST http://localhost:3000/signup \
        -H "Content-Type: application/json" \
        -d '{"name":"Alice","email":"alice@example.com","password":"secret123"}'
   ```

   You should receive a `201` response and the configured SMTP server will send the welcome email.

---

**Security note** – Never commit the `.env` file (or any real credentials) to version control. Keep it local or use a secret manager in production.
