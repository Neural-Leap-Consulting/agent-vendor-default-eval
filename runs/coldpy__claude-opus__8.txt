The one design call worth stating up front: **email sending happens after the DB commit, off the request thread, and never fails the signup.** A user who's already persisted shouldn't get a 500 because SMTP timed out.

## `app/models.py`

```python
from datetime import datetime, timezone

from flask_sqlalchemy import SQLAlchemy
from werkzeug.security import check_password_hash, generate_password_hash

db = SQLAlchemy()


def utcnow():
    return datetime.now(timezone.utc)


class User(db.Model):
    __tablename__ = "users"

    id = db.Column(db.Integer, primary_key=True)
    email = db.Column(db.String(255), unique=True, nullable=False, index=True)
    name = db.Column(db.String(120), nullable=False, default="")
    password_hash = db.Column(db.String(255), nullable=False)
    created_at = db.Column(db.DateTime(timezone=True), nullable=False, default=utcnow)
    welcome_email_sent_at = db.Column(db.DateTime(timezone=True), nullable=True)

    def set_password(self, raw):
        self.password_hash = generate_password_hash(raw)

    def check_password(self, raw):
        return check_password_hash(self.password_hash, raw)

    @property
    def display_name(self):
        return self.name or self.email.split("@")[0]

    def to_dict(self):
        return {
            "id": self.id,
            "email": self.email,
            "name": self.name,
            "created_at": self.created_at.isoformat(),
        }
```

## `app/mailer.py`

The thread only does SMTP I/O — the message is fully rendered inside the request context first, so no app context juggling in the worker.

```python
import logging
import smtplib
import threading
from email.message import EmailMessage

from flask import current_app, render_template

log = logging.getLogger(__name__)


def build_welcome_email(user):
    """Render the welcome email. Must run inside an app/request context."""
    ctx = {
        "user": user,
        "app_name": current_app.config["APP_NAME"],
        "login_url": f"{current_app.config['APP_URL'].rstrip('/')}/login",
    }

    msg = EmailMessage()
    msg["Subject"] = f"Welcome to {ctx['app_name']}!"
    msg["From"] = current_app.config["MAIL_FROM"]
    msg["To"] = user.email
    msg.set_content(render_template("email/welcome.txt", **ctx))
    msg.add_alternative(render_template("email/welcome.html", **ctx), subtype="html")
    return msg


def _deliver(msg, cfg):
    if cfg["backend"] == "console":
        print("--- EMAIL ---\n" + msg.as_string() + "\n--- END ---", flush=True)
        return

    if cfg["use_tls"]:
        with smtplib.SMTP(cfg["host"], cfg["port"], timeout=cfg["timeout"]) as smtp:
            smtp.starttls()
            if cfg["username"]:
                smtp.login(cfg["username"], cfg["password"])
            smtp.send_message(msg)
    else:
        with smtplib.SMTP(cfg["host"], cfg["port"], timeout=cfg["timeout"]) as smtp:
            if cfg["username"]:
                smtp.login(cfg["username"], cfg["password"])
            smtp.send_message(msg)


def _deliver_safe(msg, cfg):
    try:
        _deliver(msg, cfg)
        log.info("welcome email sent to %s", msg["To"])
    except Exception:
        # Never let a mail failure escape — the user is already signed up.
        log.exception("failed to send email to %s", msg["To"])


def send_async(msg):
    """Hand the rendered message to a background thread."""
    c = current_app.config
    cfg = {
        "backend": c["MAIL_BACKEND"],
        "host": c["MAIL_HOST"],
        "port": c["MAIL_PORT"],
        "username": c["MAIL_USERNAME"],
        "password": c["MAIL_PASSWORD"],
        "use_tls": c["MAIL_USE_TLS"],
        "timeout": c["MAIL_TIMEOUT"],
    }
    # daemon=False so the interpreter waits for in-flight sends on shutdown.
    threading.Thread(target=_deliver_safe, args=(msg, cfg), daemon=False).start()


def send_welcome_email(user):
    send_async(build_welcome_email(user))
```

## `app/auth.py`

```python
import logging

from email_validator import EmailNotValidError, validate_email
from flask import Blueprint, jsonify, request
from sqlalchemy.exc import IntegrityError

from .mailer import send_welcome_email
from .models import User, db, utcnow

log = logging.getLogger(__name__)

bp = Blueprint("auth", __name__, url_prefix="/api")

MIN_PASSWORD_LENGTH = 10


def _parse_signup(payload):
    errors = {}

    raw_email = (payload.get("email") or "").strip()
    email = None
    try:
        email = validate_email(raw_email, check_deliverability=False).normalized.lower()
    except EmailNotValidError as exc:
        errors["email"] = str(exc)

    password = payload.get("password") or ""
    if len(password) < MIN_PASSWORD_LENGTH:
        errors["password"] = f"Must be at least {MIN_PASSWORD_LENGTH} characters."

    name = (payload.get("name") or "").strip()[:120]
    return {"email": email, "password": password, "name": name}, errors


@bp.post("/signup")
def signup():
    payload = request.get_json(silent=True) or request.form
    data, errors = _parse_signup(payload)
    if errors:
        return jsonify(errors=errors), 400

    user = User(email=data["email"], name=data["name"])
    user.set_password(data["password"])

    db.session.add(user)
    try:
        db.session.commit()
    except IntegrityError:
        db.session.rollback()
        return jsonify(errors={"email": "That email is already registered."}), 409

    # Commit first: the account exists whether or not the mail goes out.
    try:
        send_welcome_email(user)
        user.welcome_email_sent_at = utcnow()
        db.session.commit()
    except Exception:
        db.session.rollback()
        log.exception("could not queue welcome email for user %s", user.id)

    return jsonify(user.to_dict()), 201
```

## `app/__init__.py`

```python
import logging

from dotenv import load_dotenv
from flask import Flask

from .config import Config
from .models import db


def create_app(config_object=Config):
    load_dotenv()
    logging.basicConfig(level=logging.INFO)

    app = Flask(__name__)
    app.config.from_object(config_object)

    db.init_app(app)

    from .auth import bp as auth_bp
    app.register_blueprint(auth_bp)

    with app.app_context():
        db.create_all()  # replace with Flask-Migrate for real deployments

    return app
```

## Three things to know

**The thread is a starting point, not the finish line.** It's fine for low volume, but a crash or redeploy mid-send loses the email silently, and it doesn't retry. When signup volume matters, move `send_welcome_email` behind Celery or RQ — the swap is one line in `auth.py`, since the mailer already takes a fully-rendered message. `welcome_email_sent_at` is there so a periodic job can find users who never got one.

**The 409 leaks account existence.** Anyone can probe `/api/signup` to learn which emails are registered. If that matters for your threat model, return 201 for duplicates too and instead send a "someone tried to sign up with your address" email to the existing account.

**Add rate limiting before this goes public.** As written, an attacker can drive unlimited outbound mail through your SMTP credentials by looping signups, which is a fast route to a suspended sending domain. `Flask-Limiter` on the signup route (e.g. 5/hour per IP) covers the common case.
