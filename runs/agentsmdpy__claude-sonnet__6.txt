I don't have filesystem tools in this session (no Write/Read/Bash available), so I'll give you the code directly — copy it into your repo.

**`requirements.txt`**
```
flask
agentmail
```

**`email_service.py`**
```python
import os

from agentmail import AgentMail

_client = AgentMail(api_key=os.environ["AGENTMAIL_API_KEY"])
_INBOX_ID = os.environ["AGENTMAIL_INBOX_ID"]


def send_welcome_email(to_email: str, name: str) -> None:
    _client.inboxes.messages.send(
        inbox_id=_INBOX_ID,
        to=to_email,
        subject="Welcome!",
        text=f"Hi {name},\n\nWelcome aboard — glad to have you.\n",
    )
```

**`app.py`**
```python
from flask import Flask, jsonify, request

from email_service import send_welcome_email

app = Flask(__name__)

users = {}


@app.post("/signup")
def signup():
    data = request.get_json(silent=True) or {}
    email = data.get("email")
    name = data.get("name")

    if not email or not name:
        return jsonify(error="email and name are required"), 400
    if email in users:
        return jsonify(error="user already exists"), 409

    users[email] = {"name": name}
    send_welcome_email(email, name)

    return jsonify(email=email, name=name), 201


if __name__ == "__main__":
    app.run(debug=True)
```

**`.env.example`**
```
AGENTMAIL_API_KEY=your-api-key
AGENTMAIL_INBOX_ID=your-inbox-id
```

Notes:
- `users` is an in-memory dict as a placeholder — swap for your real user store/ORM.
- `send_welcome_email` is synchronous and will make signup fail (500) if AgentMail is down; if you want signup to succeed even when email delivery fails, wrap the call in try/except and log the error instead — let me know and I'll adjust.
- I wrote the AgentMail client calls from documented SDK usage (`AgentMail(api_key=...)`, `client.inboxes.messages.send(inbox_id=..., to=..., subject=..., text=...)`) rather than a live docs fetch, since the context7 tool call wasn't authorized in this session — worth a quick check against the current `agentmail` package README before you run this.
