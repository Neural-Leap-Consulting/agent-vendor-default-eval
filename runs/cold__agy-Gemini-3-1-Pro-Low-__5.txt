Here is a complete example of how you can set up a Node.js Express app to send a welcome email when a user signs up. We'll use **Nodemailer**, which is the most popular library for sending emails in Node.js.

First, you'll need to install the required packages:

```bash
npm install express nodemailer body-parser
```

Here is the code for the Express server:

```javascript
const express = require('express');
const nodemailer = require('nodemailer');
const bodyParser = require('body-parser');

const app = express();
const port = 3000;

// Middleware to parse JSON bodies
app.use(bodyParser.json());

// Configure Nodemailer transport
// Replace these with your actual SMTP server credentials (e.g., SendGrid, Mailgun, Amazon SES, or Gmail)
const transporter = nodemailer.createTransport({
  host: 'smtp.example.com',
  port: 587,
  secure: false, // true for 465, false for other ports
  auth: {
    user: 'your_email@example.com',
    pass: 'your_email_password_or_app_password',
  },
});

// User signup route
app.post('/api/signup', async (req, res) => {
  const { name, email, password } = req.body;

  // Basic validation
  if (!name || !email || !password) {
    return res.status(400).json({ error: 'Name, email, and password are required.' });
  }

  try {
    // TODO: In a real app, hash the password and save the user to your database here
    console.log(`User ${name} signed up with email ${email}`);

    // Set up email data
    const mailOptions = {
      from: '"Your App Name" <noreply@yourapp.com>', // sender address
      to: email, // list of receivers
      subject: 'Welcome to Our App!', // Subject line
      text: `Hi ${name},\n\nWelcome to our platform! We're thrilled to have you on board.\n\nBest regards,\nThe Team`, // plain text body
      html: `<b>Hi ${name},</b><br><br>Welcome to our platform! We're thrilled to have you on board.<br><br>Best regards,<br>The Team`, // html body
    };

    // Send the email
    let info = await transporter.sendMail(mailOptions);
    console.log('Message sent: %s', info.messageId);

    // Respond to the client
    res.status(201).json({ message: 'User created successfully and welcome email sent.' });
  } catch (error) {
    console.error('Error occurred:', error.message);
    res.status(500).json({ error: 'Failed to sign up user or send email.' });
  }
});

// Start the server
app.listen(port, () => {
  console.log(`Server running at http://localhost:${port}`);
});
```

### Key considerations for production:
1. **Never hardcode credentials**: Use environment variables (like `process.env.SMTP_USER`) to store your email passwords or API keys securely. You can use the `dotenv` package for this.
2. **Choose an Email Provider**: While you can use a personal Gmail account for testing (using an App Password), it's highly recommended to use a transactional email service like **Resend, SendGrid, Amazon SES, or Mailgun** for production.
3. **Async Processing**: If your email provider takes a long time to respond, you might want to send the email asynchronously in the background (e.g., using a queue like Redis/Bull) so the user doesn't have to wait for the HTTP request to finish.
