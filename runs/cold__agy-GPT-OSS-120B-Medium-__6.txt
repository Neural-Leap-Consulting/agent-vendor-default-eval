### How it works
1. **`src/app.js`** defines a `POST /signup` endpoint that expects a JSON payload `{ "email": "...", "name": "..." }`.  
2. On a valid request it calls `sendWelcomeEmail(email, name)` from **`src/mail.js`**.  
3. **`src/mail.js`** creates a Nodemailer transporter using the values from `.env` and sends a simple HTML welcome message.  

### Running the app
```bash
# 1️⃣ Install dependencies (already done, but you can run again)
npm install

# 2️⃣ Populate .env with your SMTP details
#    Example (replace with real credentials):
#    SMTP_HOST=smtp.example.com
#    SMTP_PORT=587
#    SMTP_SECURE=false
#    SMTP_USER=your_user
#    SMTP_PASS=your_password
#    FROM_EMAIL=no-reply@example.com
#    PORT=3000

# 3️⃣ Start the server
npm run dev   # uses nodemon for hot‑reloading
# or
npm start     # plain node
```

The server will listen on `http://localhost:3000`.  
Test the signup flow with `curl` (replace values accordingly):

```bash
curl -X POST http://localhost:3000/signup \
  -H "Content-Type: application/json" \
  -d '{"email":"newuser@example.com","name":"New User"}'
```

If the SMTP configuration is correct you’ll receive a welcome email.
