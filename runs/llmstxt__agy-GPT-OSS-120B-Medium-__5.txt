### Quick start

```bash
# 1️⃣ Change to the new project directory
cd /Users/USER/.gemini/antigravity-cli/brain/9a1ffe49-64fa-43c1-9497-ff81e2d992f9/welcome_email_app

# 2️⃣ Install dependencies
npm install

# 3️⃣ Create a .env file (do NOT commit this!)
echo "AGENTMAIL_API_KEY=your‑agentmail‑api‑key" > .env

# 4️⃣ Run the server
npm start
```

The server will listen on `http://localhost:3000`.  
You can test the sign‑up flow with:

```bash
curl -X POST http://localhost:3000/signup \
  -H "Content-Type: application/json" \
  -d '{"email":"newuser@example.com"}'
```

If the request succeeds you’ll see a log entry like:

```
Welcome email sent to newuser@example.com
```
