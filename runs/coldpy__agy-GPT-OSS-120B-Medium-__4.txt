Here’s a minimal, production‑ready Flask app that:

1. **Exposes a `/signup` endpoint** (POST) that receives a JSON payload with the user’s email (and optional name).  
2. **Creates the user** (placeholder – you can hook your DB logic here).  
3. **Sends a welcome email** using **Flask‑Mail** (SMTP‑based, works with any provider – Gmail, SendGrid, Mailgun, etc.).  
4. **Returns a JSON response** indicating success or failure.

load_dotenv()

class Config:
    # Flask settings

    # Flask‑Mail settings – replace with your provider’s details

    MAIL_USE_TLS  = os.getenv("MAIL_USE_TLS", "True") == "True"

*(Keep the `.env` file out of version control; it stores secrets.)*

### `app.py` *(created for you)*

```python
#!/usr/bin/env python3
"""
Flask app that registers a user and sends a welcome email.
"""

from flask import Flask, request, jsonify
from flask_mail import Mail, Message
from config import Config

app = Flask(__name__)
app.config.from_object(Config)

mail = Mail(app)

# ----------------------------------------------------------------------
# Helper – send the welcome email
# ----------------------------------------------------------------------
def send_welcome_email(to_email: str, name: str | None = None) -> bool:
    """Send a simple welcome message. Returns True on success, False otherwise."""
    subject = "Welcome to Our Service!"
    # Personalise if we have a name
    greeting = f"Hi {name}," if name else "Hello,"
    body = f"""{greeting}

Thank you for signing up! We're thrilled to have you onboard.

If you have any questions, just reply to this email.

Best regards,
The Awesome Team
"""
    msg = Message(subject=subject,
                  recipients=[to_email],
                  body=body)

    try:
        mail.send(msg)
        app.logger.info(f"Welcome email sent to {to_email}")
        return True
    except Exception as exc:          # pragma: no cover
        app.logger.error(f"Failed to send email to {to_email}: {exc}")
        return False


# ----------------------------------------------------------------------
# /signup endpoint
# ----------------------------------------------------------------------
@app.route("/signup", methods=["POST"])
def signup():
    """
    Expected JSON payload:
    {
        "email": "user@example.com",
        "name":  "Optional Name"
    }
    """
    data = request.get_json(silent=True) or {}
    email = data.get("email")
    name = data.get("name")

    if not email:
        return jsonify({"error": "Email is required"}), 400

    # ----> Insert your user‑creation logic here (DB insert, validation, etc.) <----
    # For demonstration we just log the action.
    app.logger.info(f"Registering new user: {email} (name={name})")

    # Send the welcome email
    if not send_welcome_email(email, name):
        # If the mail fails you might still want to create the account,
        # but we surface the issue to the client.
        return jsonify({"error": "User created, but email failed"}), 500

    return jsonify({"message": "User registered and welcome email sent"}), 201


# ----------------------------------------------------------------------
# Run the app (development mode)
# ----------------------------------------------------------------------
if __name__ == "__main__":
    # In production you’d use a proper WSGI server (Gunicorn, uWSGI, etc.)
    app.run(host="0.0.0.0", port=5000, debug=app.config["DEBUG"])
```

### Running the app locally

```bash
# 1️⃣ Ensure dependencies are installed (see requirements.txt)
pip install -r requirements.txt

# 2️⃣ Create a .env file with your SMTP credentials:
cat > .env <<EOF
MAIL_USERNAME=your_email@example.com
MAIL_PASSWORD=your_smtp_app_password

# Optional overrides:
MAIL_SERVER=smtp.gmail.com
MAIL_PORT=587
MAIL_USE_TLS=True
FLASK_DEBUG=True
EOF

# 3️⃣ Start the Flask development server
python app.py
```

The server will listen on **http://localhost:5000**. Test with `curl`:

```bash
curl -X POST http://localhost:5000/signup \
     -H "Content-Type: application/json" \
     -d '{"email":"newuser@example.com","name":"Alice"}'
```

You should receive:

```json
{
  "message": "User registered and welcome email sent"
}
```

And the recipient will get the welcome email defined in `send_welcome_email`.

### Production notes

| What to consider | Recommendation |
|------------------|----------------|
| **WSGI server** | Deploy behind **Gunicorn** (`gunicorn -w 4 app:app`) or **uWSGI**. |
| **TLS/HTTPS**   | Terminate TLS at a reverse proxy (NGINX, Cloud Load Balancer). |
| **Rate limiting**| Add Flask‑Limiter or API‑gateway to prevent abuse of the signup endpoint. |
| **Email queue**  | For high volume, push email jobs to a task queue (Celery, RQ) instead of sending synchronously. |
| **Environment secrets**| Use **Google Secret Manager**, **AWS Secrets Manager**, or **Vault** in production; never commit `.env` to source control. |
| **Email template**| Replace the plain‑text body with an HTML template (use Jinja2 + `msg.html`). |
| **Testing**| Write unit tests for `signup` and `send_welcome_email` using `pytest` and `Flask‑Testing`. |
