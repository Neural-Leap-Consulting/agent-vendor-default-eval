## 1. Environment variables

Update **`.env`** with the SMTP server you’ll use for sending mail:

```dotenv
SMTP_HOST=smtp.example.com      # your SMTP host
SMTP_PORT=587                   # 465 for TLS, 587 for STARTTLS
SMTP_SECURE=false               # true if you use port 465
SMTP_USER=your_smtp_username    # SMTP auth user
SMTP_PASS=your_smtp_password    # SMTP auth password
FROM_EMAIL=no-reply@example.com # sender address shown in the email
PORT=3000                       # port the Express server will listen on
```

> **⚠️ Security note** – never commit the `.env` file to source control; the `.gitignore` entry protects it.

---

## 2. Running the app

```bash
# Install dependencies (already done)
npm install

# Start the server (development mode with hot‑reload)
npm run dev   # uses nodemon if you install it globally or as a dev dependency

# Or run directly
node app.js
```

The server will listen on `http://localhost:3000`.  

**Test the sign‑up flow**

```bash
curl -X POST http://localhost:3000/signup \
  -H "Content-Type: application/json" \
  -d '{"email":"newuser@example.com","name":"New User"}'
```

You should see a JSON response confirming the email was sent, and the mail will appear in the inbox of `newuser@example.com` (provided the SMTP credentials are correct).

# Welcome‑Email Express App

A tiny Express API that sends a welcome email when a user signs up.

## API

### `POST /signup`

**Body** (JSON):

```json
{
  "email": "user@example.com",
  "name": "User Name"
}
```

The endpoint sends a welcome email to `email` and returns:

```json
{ "message": "User signed up and welcome email sent" }
```
