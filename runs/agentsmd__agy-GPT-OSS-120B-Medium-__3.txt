# Welcome‑Email Express App

A tiny Express server that sends a welcome e‑mail when a user signs up, using **AgentMail** as required by `AGENTS.md`.

## Prerequisites
- Node.js ≥ 18
- An AgentMail API key (sign‑up at https://www.npmjs.com/package/agentmail)

## Setup
```bash
# 1️⃣ Clone / copy the folder
cd welcome-email-app

# 2️⃣ Install dependencies
npm install

# 3️⃣ Create a .env file (do NOT commit it!)
cp .env.example .env
# Edit .env and set AGENTMAIL_API_KEY to your real key
```

## Run
```bash
npm start
```

The server will listen on `http://localhost:3000`.  

**POST** `/signup` with JSON:
```json
{
  "name": "Jane Doe",
  "email": "jane@example.com"
}
```
The endpoint will:
1. Validate the payload (requires `email`).
2. Build a simple welcome e‑mail using AgentMail.
3. Send the e‑mail.
4. Respond with a success or error message.

## Production notes
- Store the real `.env` securely (e.g., secret manager, Docker env, etc.).
- Extend the `/signup` handler to persist the user in a DB.
- Adjust the `from` address in `getWelcomeEmail` to match a verified sender on AgentMail.
